1. Resumen ejecutivo

Puntuación global: 80/100 (Aceptable).

El sitio presenta una base técnica sólida en datos estructurados, pero requiere atención urgente en rendimiento (Core Web Vitals) y control de rastreo. Se han detectado 3 hallazgos Altos relacionados con tiempos de carga excesivos, bloqueo de recursos por robots.txt y un volumen considerable de URLs no indexables. La puntuación es orientativa, ya que las categorías de GEO / AI Search, Autoridad y Negocio y Conversión no pudieron ser evaluadas por falta de datos. A nivel de contenidos, el dominio posee un fuerte liderazgo informacional, aunque existe una brecha en términos comerciales frente a competidores directos. Las prioridades principales son optimizar el LCP y el tiempo de ejecución de JavaScript, auditar las reglas de bloqueo en robots.txt y depurar las URLs internas no indexables.

Parámetro Severidad Hallazgo

Impacto: El bloqueo masivo en robots.txt puede estar impidiendo el rastreo de recursos críticos o secciones importantes del sitio, afectando el descubrimiento. Los H1 y metadatos duplicados diluyen la relevancia temática de las páginas.

Recomendación: Auditar el archivo robots.txt para asegurar que no se bloqueen rutas esenciales (JS/CSS o páginas de valor). Revisar las plantillas de página para garantizar que cada URL genere un H1 y una meta description únicos. Equipo: SEO y Desarrollo.

2. Indexación y Rastreo

Nota: 70/100. Estado: Evaluada.

Parámetros evaluados en Indexación y Rastreo
Parámetro Severidad Hallazgo
Estado de indexación Alta 874 URLs internas marcadas como no indexables (19,96% del total)
Redirects (3xx) Media 213 URLs internas devuelven códigos de redirección 3xx (4,87%)
Errores 4xx Baja 16 URLs internas devuelven errores de cliente 4xx (0,37%)

Impacto: Un 20% de URLs no indexables consume crawl budget innecesariamente si estas páginas no aportan valor estratégico. Las redirecciones internas ralentizan el rastreo y la experiencia del usuario.

Recomendación: Identificar el origen de las URLs no indexables (parámetros, facetas) y bloquearlas vía robots.txt si no deben ser rastreadas. Actualizar los enlaces internos que apuntan a redirecciones 3xx para que enlacen directamente a la URL final 200 OK. Equipo: SEO y Desarrollo.

3. CWV y UX

Nota: 70/100. Estado: Evaluada.

Parámetros evaluados en CWV y UX
Parámetro Severidad Hallazgo
LCP y TBT Alta Múltiples URLs presentan LCP superior a 12 segundos y TBT crítico (ej. 14.858 ms en /products?by-need=protect-enamel)
Scripts de terceros Media Alto impacto de código de terceros en el tiempo de ejecución de JavaScript

Impacto: Tiempos de LCP y TBT tan elevados resultan en una calificación "Poor" en Core Web Vitals, lo que perjudica directamente la experiencia del usuario, la tasa de conversión y actúa como un factor de ranking negativo en Google.

Recomendación: Implementar técnicas de code splitting, diferir la carga de JavaScript no crítico (defer/async) y optimizar la entrega de imágenes (formatos modernos, preload para la imagen LCP). Revisar y limitar el uso de scripts de terceros. Equipo: Desarrollo.

7. Limitaciones

  • Discrepancia de mercado: El dominio analizado es colgate.com.br (Brasil, idioma portugués), pero las instrucciones del usuario indican que el sitio está dirigido únicamente a público hispanohablante en México y no dispone de datos hreflang. Se ha procedido con el análisis de los datos proporcionados, pero esta contradicción debe ser revisada estratégicamente.
  • Discrepancia de datos hreflang: La memoria del usuario indica que no hay datos hreflang, pero el archivo de rastreo muestra 1.222 páginas con hreflang implementado (aunque faltan etiquetas X-Default). Se ha evaluado basándose en los datos del rastreo.
  • Categorías no evaluadas: Las categorías GEO / AI Search, Autoridad y Negocio y Conversión no pudieron ser evaluadas por falta de archivos de datos correspondientes.
  • Supuestos de marca: Se han inferido los términos de marca ("colgate", "tandy", "periogard", "orthogard", "plax", "oralb", "odontoclinic", "listerine") para la exclusión en el análisis de palabras clave, ya que no fueron proporcionados explícitamente.
  • Intención inferida: La intención de búsqueda en la Tabla A fue inferida a partir de los datos proporcionados en el archivo de posiciones.
